How to install

  1. Choose the 64-bit version unless your device specifically requires the 32-bit version.
  2. Download the APK to your Android device.
  3. Open the file and follow Android's installation prompts. Allow installation from your browser only if you trust this website.
  4. Open UP NaukriGuru and create or sign into your student account.
